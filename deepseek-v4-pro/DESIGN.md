### 3. 核心冲突

1. **贫与富、体面与取乐**：凤姐与鸳鸯合谋「拿他取个笑儿」，刘姥姥心知肚明却选择配合，以自嘲换得贾母欢心与贾家的照应——这是穷人的生存智慧与自尊体面之间的张力，也是本作整套选择系统的来源。
2. **雅与俗、奢与俭**：贾母的富贵审美（给宝钗摆陈设、论软烟罗「糊窗子岂不可惜」）与宝钗「雪洞一般」的素净、刘姥姥「竟比那画儿还强十倍」的惊叹，构成阶层与审美之间的张力。

## 二、设计

### 1. 主角是谁，为什么选这个视角

主角是**刘姥姥**。她是本回唯一贯穿始终的人物：从进园到离席，走遍大观楼前、沁芳亭、潇湘馆、秋爽斋、荇叶渚、蘅芜苑、缀锦阁七个地点，与贾母、凤姐、鸳鸯、黛玉、宝钗、探春、惜春、宝玉、湘云等所有人照面。更重要的是，她的「乡下穷亲戚」身份让每一个选择都同时关乎**体面**与**生存**——这是最有戏、最贴合原著张力的视角。

### 2. 核心愿景

让玩家化身刘姥姥走进大观园，亲历「被取乐」与「守体面」之间的两难，在贫富、雅俗的碰撞中自己做决定，最后抵达一个与原著相符、或由自己的选择改写的一天。读过原著的人能认出每一个地方、每一句话的口吻；没读过的人也能玩懂、觉得有意思。

### 3. 设计支柱

1. **视角即张力**：以刘姥姥「外人 + 穷人」的身份为镜头，所有选择都从她的处境与动机出发。
2. **选择即取舍**：每个选择都对应原著里真实的两难（配合还是拒绝、自嘲还是反击、本色还是藏拙），不外加任何与故事无关的系统。
3. **一句一句忠实**：对白尽量直接引用或轻微改写原文，保留人物口吻、称谓与时代感，通篇不用现代网络用语。
4. **一园一步**：七个地点皆取自原文，画面古典、彼此明显不同；边走、边看、边聊，节奏像一次游园。
5. **结局忠于因果**：三个结局中「满堂欢」对应原著走向，另外两个是玩家选择导致的合理偏离，不与原著冲突。

### 4. 不做什么（刻意没有改编进来的内容，及原因）

- **不加战斗、收集、数值养成等无关系统**：它们与这段「游园 + 人情」的故事无关，会稀释核心张力。
- **不完整模拟牙牌令的每一副牌与韵脚规则**：牙牌的具体牌型对现代玩家过于琐碎、不构成戏剧张力；游戏保留「酒令大如军令」的气氛与众人对句，只在刘姥姥的回合给玩家真正的选择。
- **不改编本回之后的内容**：片段止于这一日收场，不续写第四十一回之后刘姥姥的后续。
- **不做音频**：评测只考察画面与操作。
- **不引入与原著冲突的人物、情节或对白**：所有补充都只是过渡句。

### 5. 玩家会经历什么（从开场到每一个结局）

1. **标题画面**：书名、章回名、开始按钮、操作提示。
2. **引子**：交代时间（这日天气清朗）、地点（荣国府大观园）、主角（刘姥姥）与动机（开眼界，也盼贾母欢喜、往后照应乡下的一家子）。
3. **大观楼前**（景一）：与凤姐对话 → **选择一（戴花）**。
4. **沁芳亭**（景二）：陪贾母看园子，夸「比画儿还强十倍」。
5. **潇湘馆**（景三）：滑倒、错认书房、听贾母论软烟罗并受赠纱。
6. **秋爽斋**（景四）：早饭 → **选择二（取笑与否）**；饭后 → **选择三（赔不是）**。
7. **荇叶渚船上**（景五）：听宝玉、黛玉、宝钗论残荷。
8. **蘅芜苑**（景六）：看宝钗「雪洞」屋子，贾母亲为布置。
9. **缀锦阁酒席**（景七）：行牙牌令 → **选择四（本色还是罚酒）**。
10. **结局**：根据四个选择的累积结果，进入**满堂欢**（原著）、**守拙归去**、**不欢而散**之一，然后可回到标题重开。

结局判定：若曾「拔花摔向凤姐」→ **不欢而散**；否则若「早饭配合取笑」且「牙牌令说本色话」→ **满堂欢**（原著）；其余 → **守拙归去**。

## 五、运行说明

### 启动方法（任选其一）

- **方法一（推荐，最直接）**：在 Chrome 中打开 `index.html`（双击文件，或地址栏输入其路径）。无构建、无依赖、无网络请求。
- **方法二（命令行）**：在项目目录执行
  ```bash
  python3 -m http.server 8000
  ```
  然后在 Chrome 打开 `http://localhost:8000/`。
- **方法三（macOS 一条命令）**：在项目目录执行
  ```bash
  open -a "Google Chrome" index.html
  ```

> 说明：游戏为纯静态网页，所有画面、人物、对白均由代码绘制/内置，无外部图片、字体、音频或网络依赖；在离线环境与 `file://` 协议下均可正常运行。

### 操作说明

- **← → 或 A / D**：左右行走；走到画面左右边缘即可切换地点。
- **E 或 空格**：与附近人物交谈、推进对话。
- **回车**：推进对话。
- **鼠标**：点击对话框推进；点击选择按钮做出选择；对话选择也可用数字键 **1 / 2**（或甲 / 乙）。
- 画面顶部显示当前地点、目标提示与进度（第 n / 7 景）；靠近人物或出口时会给出提示。
