# 画里人家：第四十回的一日游园

成品是一个无需安装依赖的离线网页叙事探索游戏。玩家扮演刘姥姥，行走于五个地点，与八位原著人物（含主角）相遇或交谈，作出五处两选一的选择，抵达三个结局之一。正常阅读与游玩约 12–18 分钟。作品止于本回末，不续写下一回的事件。

唯一的文学底稿是同目录 `SOURCE.txt`。未检索、引用其他版本、解读或改编。文中的原句定位保留底稿用字；游戏部分对白改用常用字与现代标点。所有背景、人物、头像、器物、纹理与动画均由 Canvas / CSS / 内嵌程序纹理绘制，没有下载或调用图像、模型、字体、音频或生成接口。

“园中记”不是原著人物，是明确的叙述框，用于交代省略的群体动作、转场和主角心绪。

### 核心冲突

1. **被取笑与主动凑趣同时存在。** 象牙箸、鸽子蛋是身份差距下的撮弄，但“你先嘱咐我，我就明白了”“我要心里恼，也就不说了”又确认了刘姥姥自己的知情与能动。不能把她写成全然不懂，也不能把这一席写成完全对等的玩笑。
2. **富贵的体面与庄家的本色彼此照见。** 软烟罗拿来糊窗、宝钗的素净被批评、牙牌令容许俗话，都让玩家看见“得体”有一套主人家的标准；刘姥姥最后用庄家的经验进入了这个场合。

## 二、设计

### 主角视角

选择刘姥姥，而非旁观的宝玉或掌控席面的凤姐。她走过本回大部分地点，对器物新奇，且正好处在“受款待”和“供人发笑”的交界。新读者与她一起认识园子，熟悉原著的读者则能主动作出那些明白而肯为的选择。

玩家没有读心权。凤姐与鸳鸯在她不在场时的密谋，不作为主角亲耳听见的事实。她从私下嘱咐、器物与席面中作判断。

### 核心愿景

**让玩家在满园的好意与笑声里，决定自己如何领情、如何说话。** 从一枝花到一句“大倭瓜”，行动始终属于这一天，而不是外加的胜负系统。

### 设计支柱

1. **走进器物与空间。** 五景有各自构图和色调；调查书案、菊花、佛手与茶具后形成见闻，理解人物如何住在空间里。
2. **选择小而真。** 不以揭露贾府、改变家族命运等外加目标驱动，只选择戴花、走路、凑趣、赔话和接令。
3. **知情的主角。** 对白保留刘姥姥的聪明、自嘲和庄家比喻；顺着原文应酬不是“失败选项”。
4. **后果可辨。** 花冠立刻改变角色与头像；是否跌倒改变位置、见闻与琥珀后话；落蛋与桌上小碗区分席面分支；赔话改变鸳鸯在末席的招呼；结局与记录回收选择。
5. **从容而完整。** 无倒计时、战斗、数值惩罚和随机判定；自动走近交谈、可回访园景、随时翻阅见闻，并明确抵达结局。

### 不做什么

- 不模拟整个大观园，不编造本回之外的地理连通关系；园图只是本日游踪。
- 不逐一塑造所有在席人物。复杂笑态用集体叙述与画面中的反应合并，确保读者不会因认人受阻。
- 不加入银钱、好感数值、道德评分或“讨好贵人换奖赏”的循环。赠纱是本回事件，不是游戏交易奖励。
- 不把牙牌令做成知识考试。主角的庄家语言就是内容，不要求玩家懂古典诗词或骨牌算法。
- 不做泛舟操舵、舞台演奏、板儿管教等副玩法。这些会稀释核心的人情选择。
- 不续写外面的乱嚷，不解释本回未明说的事情。

### 从开场到结局

1. **标题。** 书名、回目、秋园背景；“入园”进入。已有存档时可续上。引子说明清秋、地点、主角、板儿同行和领情应对的愿望。
2. **沁芳亭。** 可先与李纨、贾母交谈，也可调查菊花盘。找凤姐决定簪满头或只留一枝（C1）。前路开启。
3. **潇湘馆。** 琥珀提醒苍苔滑，选让路或走石径（C2）。可看书案、与黛玉交谈。与贾母听软烟罗一段，开启下一站。画面窗下出现“明日换银红窗纱”的小字，窗色当日不变。
4. **秋爽斋。** 找鸳鸯，听私下嘱咐，决定按话凑趣或先换箸（C3）。原著路线发生大笑、落蛋、贾母换箸；分支先换箸，照样愿意说笑但不落蛋。再找鸳鸯接赔话（C4），可原样解围，也可轻声提出分寸。之后沿荇叶渚乘船的过程以文本过场压缩。
5. **蘅芜苑。** 可与宝钗说话、调查土定瓶。与贾母谈素室陈设，听鸳鸯答应明后日送来，开启末席。
6. **缀锦阁。** 贾母提酒令，凤姐荐鸳鸯。与鸳鸯交谈进入规则与最终选择（C5）。以庄家话接令时，代码绘制的三张牙牌同时展出，四次牌面提示与四句原文答话逐步呈现；或按既有规则罚饮一杯。
7. **结束。** 原著组合到“一席本色”；此前有任一非原著选择而最后仍接令，到“笑里有度”；最后选择饮酒，到“且饮一杯”。结局页说明原著/分支、回顾选择，可查看见闻或返回标题重开。

## 四、偏离清单

1. **合并：** 簪花移至沁芳亭附近，清晨备器与前夜筹席只留对白。使开场有一处完整可游玩的场地，未颠倒主要事件顺序。
2. **合并：** 潇湘馆的门前苔路和室内以同一画面剖面呈现；秋爽斋晓翠堂与探春房中陈设并置。舞台视角不是现实中的无墙房屋。
3. **删减：** 其他席上成员、丫鬟、仆役、驾娘、女乐大多不绘制为角色；其行动由叙述概括。画面显示的是叙事代表人物，不声称原文现场只有这些人。
4. **删减：** 板儿的乱摸、挨打、哭与劝解；薛姨妈迟到；全部前席诗令；黛玉戏文引起宝钗注意；饭后分菜的详细过程；刘姥姥将离席被拉回的反复动作。保持视角集中且不引入没有在本回解决的新支线。
5. **补充：** 主角的短篇内心话、凤姐对只留一花的反应、琥珀后续关照、黛玉的待客台词、宝钗与主角的短谈。界面标“补写”“据情节补写”或“选择分支”，不冒充原文对白。
6. **改动（玩家选择）：** 一枝菊花、避过跌倒、提前换箸而不落蛋、赔话时说明分寸、最后不接令而罚酒。均有相邻原文事件作为触发，不另造敌人、危机或超出本回的结果。
7. **推定：** 允许主动辞过一轮并按罚酒处理。原文写明错令罚一杯，并未写刘姥姥使用该做法；因此独立标为分支结局，不与原文混同。
8. **合并：** 泛舟为两站之间的文字过场；前往蘅芜苑时只述棠木舫、残菱衰草，不把另一船上的诗句写成主角亲耳听到。
9. **推定：** 自绘服装颜色、发式细节、建筑构图和山水画，不是服饰考据复原；依本回人物身份作朴素老人、华丽凤姐、尊长与姑娘的视觉区分。不使用现代器物或网络口吻。
10. **补充（视觉提示）：** 软烟罗对话完成后窗下出现“明日换银红窗纱”提示，原文施工不在当日，因此窗色仍保留绿色。见闻只记录吩咐赠纱，未凭空发放实物。蘅芜苑也只出现“陈设明日送来”文字，不提前布置新器物。
11. **删减与改写：** 省去原文一处粗俗动词和菜中验毒的往返笑话；“著”等按原意转换用字。保留“大似牛”“一两银子没听见响声”“大倭瓜”等决定人物口吻的句子。
12. **推定（交互抽象）：** 园图可返回已开地点，人物仍在对应场景供回访；不是众人在故事时序中分身。回访台词用于确认选择后果，主线时间只向前推进。
13. **补充（结局）：** 结局的总结性文字是对玩家这一天的回顾；“原著情节走向”仅在前四次皆取原文行动且末席本色接令时成立。其余明确标分支，不推出后续人物关系、家族命运或经济奖励。

## 五、运行说明

### 启动

**最直接的方式：在 macOS 的 Chrome 中打开本项目的 `index.html`。** 不需要 Node、打包、安装、联网或服务器。所有脚本为普通脚本，不依赖模块导入或 `fetch`。

也可以在项目目录用一条命令启动静态服务器：

```sh
python3 -m http.server 8000
```

再在 Chrome 访问 `http://localhost:8000`。此方式需要系统已有 Python 3；直接打开文件的方式没有此要求。

画布逻辑尺寸 1280×720，外层按窗口等比缩放并留边。中文使用系统字体回退链：macOS 的 Songti SC、Linux 的 Noto Serif CJK SC、SimSun、系统 serif。没有外链字体；中文保留为 UTF-8 正文，不转图片。

### 操作

- **开始：** 标题点“入园”，阅读引子后点“走进园中”。
- **行走：** WASD / 方向键；或点击地面自动走到。角色脚下浅色圆环是玩家标记。
- **人物：** 点击人物会自动走近并开始交谈；也可走近后按 E 或点击浮动交谈按钮。头顶小圆感叹号标当前推进人物。
- **调查：** 点物件旁的浅色圆点，或走近按 E。调查记录存入见闻。
- **对话：** 点“听下去 / 继续”，或空格、Enter、E。选择用鼠标按钮或数字 1、2；不会因空格误选。
- **换景：** 走至右侧写明目的地的园路，再按 E；点击路牌也可自动前往。M 或右上“园图”可前往所有已开地点。
- **见闻：** J 或右上“见闻”；结局也能回看。
- **暂停：** Esc 或右上菜单。关闭弹层后继续；暂停时不移动。
- **重开：** 结局点“再入画中”回标题，再点“入园”；暂停菜单也能回标题。
- **存档：** 地点、选择与见闻自动写浏览器本地存储；标题“续上这一日”恢复对应场景，不恢复到一段对话的某个字。禁用本地存储仍可完整游玩，只是没有跨刷新续玩。

### 评测跳转点

跳转使用 `#jump=编号`。每次读取或改变该 hash 都独立重建先前状态，不依赖存档，不需要先通关。选择跳转**直接显示两个可点击选项**，没有需要先走过去或跳过的前置对话。每个结局跳转也可立即查看见闻或重开。

|编号|对应状态|服务器示例|
|---|---|---|
|`c1`|沁芳亭 · 簪花选择|`http://localhost:8000/#jump=c1`|
|`c2`|潇湘馆 · 苔路选择；此前原著簪花|`http://localhost:8000/#jump=c2`|
|`c3`|秋爽斋 · 入席与牙箸选择；此前原著路径、已听软烟罗|`http://localhost:8000/#jump=c3`|
|`c4`|秋爽斋 · 饭后赔话选择；已表演原著宴席|`http://localhost:8000/#jump=c4`|
|`c5`|缀锦阁 · 本色接令或饮酒选择；此前原著路径、已过蘅芜苑|`http://localhost:8000/#jump=c5`|
|`end-original`|“一席本色”原著走向结局|`http://localhost:8000/#jump=end-original`|
|`end-measured`|“笑里有度”选择分支结局|`http://localhost:8000/#jump=end-measured`|
|`end-quiet`|“且饮一杯”选择分支结局|`http://localhost:8000/#jump=end-quiet`|

直接打开文件时，在浏览器地址末尾加上同样的 hash，例如 `file:///你的项目路径/index.html#jump=c3`。去掉 hash 后刷新会回标题，不会继续强制跳转。

没有影响玩法的随机事件。背景点纹、枝叶布局使用固定种子 42 和固定树木种子；飘叶、呼吸动作只使用启动后的经过时间，不影响选项、判定和结果。评测跳转记录可能只含用于上下文的一条见闻，正常游玩会完整积累。
