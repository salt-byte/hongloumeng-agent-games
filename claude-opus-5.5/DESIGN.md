### 3. 核心冲突

- **取悦与体面**：刘姥姥为了替穷亲戚家讨一份长久的照应，要让贾母开心；而让贾母开心的方式，恰是凤姐、鸳鸯把她当“女篾片”取笑。她“心里明白”，自愿配合——原著最耐人寻味的张力，正在“我要心里恼，也就不说了”这一句里。
- **村俗与雅致**：一个庄家老妪闯进“画儿上”的园子，满眼看不懂的软烟罗、法帖、比目磬；到了牙牌令，满座诗词歌赋，她只有“萝卜”“大倭瓜”。她靠的是**本色**而不是模仿。

## 二、设计

### 主角与视角
主角是**刘姥姥**。这一回几乎每一件事都围绕她发生：插花、跌跤、象牙筷、鸽子蛋、牙牌令。更重要的是，只有在她的视角里，“被取笑”与“哄老太太开心”之间的分寸才是一个真正需要决定的问题——玩家要替她拿捏这份分寸。

### 核心愿景
让玩家以一个“局外人”的身份走进大观园，一面惊叹于这座“比画儿还强十倍”的园子，一面在笑声里掂量自己的位置：是陪着演，还是守住体面；是说自己的本色话，还是学人家的雅句。

### 设计支柱
1. **原著的一天**：七个场景顺着原著的游园路线（大观楼→沁芳亭→潇湘馆→秋爽斋→荇叶渚→蘅芜苑→缀锦阁下）展开，所有台词尽量采自原文。
2. **选择即分寸**：每个选择点都是原著里刘姥姥实际面对的“接不接这个笑话”的时刻，而非外加的系统。
3. **看得见的后果**：满头花还是一朵花直接画在人物头上；饭桌上有无“老母猪不抬头”；鸳鸯此后的口气；最终三种结局。
4. **一草一木皆从书里来**：苍苔石子路、湘帘、旧绿纱、烟雨图与颜鲁公对联、白玉比目磬、土定瓶、青纱帐、残荷，都能在画面上找到。
5. **人情簿**：左下角三项“老太太欢心 / 凤姐鸳鸯情分 / 庄家人本色”，把原著里那种看不见的人情账可视化，只是对剧情张力的提示。

### 不做什么
- **不做第三十九回、四十一回的情节**（栊翠庵品茶、醉卧怡红院等），只到“只听外面乱嚷”为止，保持本回的完整性。
- **不做牙牌令的全部轮次**：薛姨妈、湘云、宝钗的整副牌词压缩为一句叙述，避免冗长；保留贾母全副、黛玉的《西厢》《牡丹》句（宝钗回头看他的伏笔）与迎春被罚。
- **不保留原文粗俗字**：“肏攮”改为“攮”，口吻仍在。
- **不做分送剩菜给平儿、袭人的琐事**：与主角关系不大。
- **不做音效**（评测不要求）。
- **不做小游戏或数值玩法**：人情簿只是剧情反馈，不设失败。

### 玩家会经历什么
1. **标题**：书名、回目、水墨远山与大观楼，落菊飘飞。“开始游戏”/“选段跳转”。
2. **第一折 晨开缀锦阁（大观楼前）**：引子交代时间（次日清早）、地点（大观园）、身份（刘姥姥）、心愿（讨老太太欢喜）。找李纨，登梯看缀锦阁，贾母一行进园，凤姐插花 → **选择一**。
3. **第二折 画儿上的园子（沁芳亭）**：过曲桥到亭上，贾母问“园子好不好”，刘姥姥说画儿，夸惜春。
4. **第三折 苍苔与软烟罗（潇湘馆）**：沿石子路走入竹林，自动触发跌跤；进屋可查看书案（“哥儿的书房”），陪贾母说话引出薛姨妈与软烟罗，贾母许送两匹。
5. **第四折 女篾片（秋爽斋）**：远远看见凤姐鸳鸯咬耳朵；鸳鸯拉出嘱咐 → **选择二**；入座小楠木桌，早饭按选择分两版；饭后 → **选择三**；到探春卧室查看佛手、磬、花囊、烟雨图、纱帐（板儿小选择）；鼓乐声起，贾母定在缀锦阁下吃酒。
6. **第五折 留得残荷听雨声（荇叶渚 → 池上 → 蘅芜苑）**：岸上可听宝玉、宝钗、黛玉论残荷；上船后凤姐撑篙；拢岸进蘅芜苑，贾母叹“这孩子太老实了”。
7. **第六折 金鸳鸯三宣牙牌令（缀锦阁下）**：按原著席次入席；“酒令大如军令” → **选择四**；轮到刘姥姥“四四是个人” → **选择五**。
8. **结局**（三种），结局画面回顾玩家的全部抉择与人情簿，可回到标题重开。
   - **结局一「花儿落了结个大倭瓜」（原著）**：以庄家本色作答，满座大笑，外面乱嚷。文字随前面的选择而变（应承/婉拒、是否点破一句、软烟罗）。
   - **结局二「辞席归家」**：正色告辞并拒绝贾母挽留，带板儿离园。
   - **结局三「画虎不成」**：硬学雅句，说出迎春刚被罚的“桃花带雨浓”，席间冷场。

## 五、运行说明

### 启动
- **最简单**：在 macOS 上直接用 Chrome 打开项目根目录下的 `index.html`（双击或拖进 Chrome）。不需要网络、不需要安装任何依赖。
- 或者在项目目录运行一条命令起本地服务器后访问：`python3 -m http.server 8000`，然后打开 `http://localhost:8000/`。
- 中文使用系统字体（macOS 上为宋体-简/楷体-简/苹方，Linux 上为 Noto CJK），不会出现方框。

### 操作
| 操作 | 按键 |
|---|---|
| 行走 | 方向键 / WASD；或鼠标点击地面移动 |
| 交谈 / 查看 | 走近人物或发光的物件后按 空格 / 回车 / E；或直接用鼠标点击人物、物件 |
| 推进对白 | 空格 / 回车 / 鼠标点击（第一次点击显示全文，第二次翻页） |
| 选择 | 鼠标点击选项，或数字键 1/2/3，或 ↑↓ + 回车 |
| 场景切换 | 走到闪烁的出口标牌处（如“往沁芳亭 →”） |
| 结局后 | 点击“回到标题”或按回车 |

右上角显示当前目标，左上角显示段落标题与地点，左下角“人情簿”显示三项人情。
