#### 刘姥姥（玩家角色）
- **身份**：乡下人，贾母留她在园中热闹一天；带着孙子板儿。原著称她「刘亲家」，与贾府有旧亲往来。

### 1.3 核心冲突

1. **笑声与体面**：贾府众人用「女篾片」式的取笑来款待刘姥姥，刘姥姥也主动配合；但每一次配合都在问：她是在以自己的乡野本色赢得情分，还是在把自己变成任人取笑的笑话？
2. **好意与分寸**：贾母对宝钗「雪洞」屋子的干预，出于长辈的疼爱与体面观念；宝钗的素净则是她自己的性情。夹在中间的刘姥姥，必须选择顺着谁、护着谁，还是替两边圆场。

## 二、设计

### 2.1 主角是谁，为什么选这个视角

玩家扮演 **刘姥姥**。

她是这一回里唯一从园外走进园中的人：既看得见大观园的富丽，也看得见这富丽背后的规矩与眼色。用她的视角，玩家天然拥有三重优势：

1. **空间上的移动理由**：她是客人，可以跟着贾母从沁芳亭走到潇湘馆、秋爽斋、蘅芜苑、缀锦阁，五个地点串成一条自然的游园路线。
2. **情感上的两难**：她既要让贾母尽兴，又要为板儿、为自己留体面；每一个笑点都可能成为选择。
3. **主题上的焦点**：这一回最动人的地方，不是贾府如何富，而是一个乡下老妇如何在被取笑时仍然保持尊严与善意。玩家替她决定「笑到什么程度」，就是在替这一回找角度。

### 2.2 核心愿景

**把原著里那阵笑声交到玩家手里。**

让玩家走进秋日的大观园，在五个可以行走的场景里，与贾母、凤姐、黛玉、探春、宝钗、鸳鸯等人说话；在簪花、认错书房、软烟罗、管教板儿、女篾片、鸽子蛋、素净屋子、牙牌令这八个时刻，决定刘姥姥是凑趣、是收住，还是巧妙转圜。最后，依据这些分寸，抵达「尽兴而归」「体面而还」或「秋窗余兴」三种结局。

读完原著的人，会认出「老刘老刘」「花儿落了结个大倭瓜」「留得残荷听雨声」「礼出大家」；没读过的人，也能看懂一个乡下奶奶在豪门宴席上的局促、机智与善意。

### 2.3 设计支柱

1. **以刘姥姥的眼睛看园子**：所有场景都从她的陌生化视角构图——竹子、纱窗、佛手、鸽子蛋、牙牌，都是新鲜而具体的。画面用米纸、墨、石绿、朱砂与金，保持工笔淡彩的秋园气息。
2. **每一个笑点都是一次分寸选择**：不把「取笑」简单做成对错题。凑趣有凑趣的温暖，收住有收住的尊严，转圜有转圜的智慧；三种都可能有得有失。
3. **原著场景就是可行走的空间**：五处地点各有明显不同的色温、建筑、植被与声音感（无音频，以画面暗示），有出入口、园图与明确的目的地提示。
4. **情分与体面双轨，不做道德裁决**：界面上的「情分」「体面」只是两条拉力，不是善恶值；结局评价的是这一日的分寸，而不是玩家「赢没赢」。
5. **短而完整，可重游**：一次游园约 20 分钟；八个选择点、三个结局、可直接跳转的评测点，让片段既能完整玩，也能被反复检查。

### 2.4 不做什么

- **不改编第四十一回**：不写刘姥姥醉卧怡红院、栊翠庵品茶、妙玉等后续情节，避免超出「第四十回」的范围。
- **不做宝黛爱情线**：本回的重心是宴游与取笑，不是爱情；宝玉、黛玉只作为席上人物出现。
- **不把刘姥姥写成纯粹的丑角**：她的自嘲是主动的生存智慧，不是供人消费的愚蠢。游戏允许玩家拒绝「女篾片」的笑话。
- **不添加原创反派、战斗、解谜或养成系统**：所有选择都来自原著事件本身的张力；「情分／体面」只做轻量反馈。
- **不使用现代网络用语、穿越梗、流行语**：对白以原著口吻为底，适度改成易读的现代汉语语序。
- **不下载任何外部图片、模型、字体、音频**：画面全部由 Canvas 2D 与 CSS 代码绘制；中文字体使用系统自带的宋体／Noto Serif CJK 字体栈。
- **不做音频**：评测不考察音频，项目保持纯画面。
- **不呈现原著中过于直露的粗俗字眼**：如「肏攮」等，以「尝一个」「夹」等动作替代，保留情境与人物语气。
- **不把结局做成惩罚**：没有「坏结局」；三个结局都是刘姥姥在特定分寸下的合理去处。

### 2.5 玩家会经历什么

#### 开场
标题画面《红楼梦》第四十回，秋园、圆月、沁芳亭、菊花与飘落的秋叶。点击「入园」，进入引子：清早，露水未干，刘姥姥带着板儿进大观园；她想陪老太太热闹一天，也不愿成为任人取笑的笑话。

#### 第一折 · 沁芳亭
与贾母、凤姐、惜春、板儿同处一亭。凤姐把一盘菊花插满刘姥姥的头。
- **C1 簪花**：凑趣 / 只簪一朵 / 把花给板儿。
- 结果：贾母、凤姐的反应不同；情分与体面开始分岔。之后得知下一站是潇湘馆。

#### 第二折 · 潇湘馆
翠竹、苍苔、石子小路；刘姥姥滑倒，贾母笑骂丫头；黛玉奉茶。
- **C2 认错书房**：用原著「比上等书房还好」的赞语 / 夸黛玉「神仙姑娘」 / 自认眼瞎。
- 接着是「软烟罗」：贾母讲纱、凤姐取纱、贾母赠纱。
- **C3 受赠**：推辞 / 欢喜领赏 / 说笑赞纱。
- 结果：黛玉、凤姐、薛姨妈、鸳鸯的态度与礼物归属被记录。之后往秋爽斋。

#### 第三折 · 秋爽斋
探春的阔朗屋子，大理石案、白菊、佛手、绿纱帐。板儿伸手去扯帐上绣花。
- **C4 管教板儿**：按原著打他一巴掌 / 拉住赔礼 / 自嘲解围。
- 席上，鸳鸯与凤姐设下「女篾片」的局，象牙镶金筷子与鸽子蛋摆到面前。
- **C5 女篾片**：说「老刘，老刘，食量大似牛……」 / 只说自己会吃 / 反敬凤姐、把话头绕回去。
- **C6 鸽子蛋**：叹「一两银子，也没听见响声儿就没了」 / 笑蛋比鸡金贵 / 悄悄夹给板儿。
- 饭后鸳鸯赔不是，刘姥姥说「咱们哄着老太太开个心儿，可有什么恼的」，保留原著的和解。之后往蘅芜苑。

#### 第四折 · 蘅芜苑
舟行过荇叶渚，残荷、衰草、黛玉的「留得残荷听雨声」。进蘅芜苑，雪洞般的屋子，贾母摇头。
- **C7 素净屋子**：顺着贾母 / 护着宝钗 / 以「一瓶菊花」圆场。
- 贾母命鸳鸯取盆景、桌屏、冻石鼎、白绫帐子。之后往缀锦阁。

#### 第五折 · 缀锦阁
黄昏水亭，红烛、灯影、宴席。鸳鸯主令，众人行牙牌令；轮到刘姥姥。
- **C8 牙牌令**：说完整的庄家令 / 求饶吃三杯 / 只说头一句便收住。
- 依据这一日的分寸进入三个结局：

**结局一 · 尽兴而归（原著之径）**
> 需要：C5 选择「老刘老刘」、C8 选择完整的庄家令，且情分 ≥ 12。
> 满园笑声，贾母落泪，鸳鸯斟酒；刘姥姥坐在老太太下手，觉得这园子再大，此刻也有一角容得下自己。引原著末句「花儿落了结个大倭瓜」。

**结局二 · 体面而还（另一种分寸）**
> 触发：C8 选择求饶吃三杯。
> 刘姥姥没有说那句「老刘老刘」，吃了三杯，贾母不勉强；她带着软烟罗与攒盒菜，从二门体面地出去。笑声还在身后，但不是她的。

**结局三 · 秋窗余兴（半日清欢）**
> 触发：C8 只说头一句，或 C5 未说完整的「老刘老刘」，或情分不足 12。
> 满席笑了一阵便转去说别的；最热闹的一阵笑没有响起来。散席后她走过沁芳亭，觉得这一日像做了半场好梦，梦没做完，也不算坏。

三个结局都可「再游一园」或「回到标题」，重开时所有状态、统计与选择清空。

## 五、运行说明

### 5.1 启动方法

项目是纯静态网页，**不需要安装依赖，不需要联网**。

**macOS（推荐，一条命令）**

```bash
cd /path/to/project
open index.html
```

或直接双击 `index.html`，在 Chrome 中打开。

如果系统默认浏览器不是 Chrome：

```bash
open -a "Google Chrome" index.html
```

也可使用附带的启动脚本：

```bash
./start.sh
```

脚本在 macOS 上会优先用 Google Chrome 打开 `index.html`，找不到 Chrome 时再用系统默认浏览器。若需要本地服务器：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000/index.html
```

> 评测电脑为 macOS + Chrome；项目没有任何构建步骤，`file://` 直接打开也可运行（已在本机 Chromium 的 `file://` 模式下验证）。

### 5.4 工程说明

- 技术：原生 HTML5 + CSS + Canvas 2D + JavaScript，无框架、无构建、无外部依赖。
- 文件：`index.html`（界面）、`styles.css`（版式与纸墨风格）、`game.js`（场景、角色、对白、选择与结局逻辑）。
- 画面：所有背景、人物、菊花、竹、窗、灯、地图、标题画面均由代码绘制；无外部图片、字体、模型、音频。
- 分辨率：逻辑画布固定 1280×720，通过等比缩放适配浏览器窗口；在 1280×720 下无重叠、无截断。
- 字体：优先 `Songti SC` / `STSong` / `Noto Serif CJK SC`，Windows 后备 SimSun；已在 Linux/Chromium 中验证中文正常显示；macOS 使用系统自带的 Songti SC / STSong 字体栈，不依赖下载字体。
- 可重开：标题、暂停菜单、结局画面均可回到标题或重新开始；重开清空所有状态。
