### 3. 核心冲突

1. **体面与凑趣**：凤姐、鸳鸯存心拿刘姥姥当“女篾片”取笑；姥姥心里明白，却选择装憨逗乐——“咱们哄著老太太开个心儿”。她是任人摆布，还是以自嘲换来尊重与实惠？
2. **两个世界的相撞**：庄家人的眼睛看软烟罗糊窗、一两银子一个的鸽子蛋、雪洞般的闺房——富贵的精致与乡野的本色彼此照见，笑声里有天真，也有隔阂。

## 二、设计

### 1. 主角与视角
主角是**刘姥姥**。这一回几乎全程跟着她的脚步走遍大观园；所有的张力（被打扮、被嘱咐、被罚令）都落在她身上；而原著里她每一次“出丑”其实都是清醒的选择——这正好化为玩家的选择。

### 2. 核心愿景
**“做一日刘姥姥：在画儿一般的园子里，每一次被人取笑，都由你决定是凑趣，还是守住体面。”**

### 3. 设计支柱
1. **选择即原文的岔口**：每个选择点都设在原著里姥姥开口（或本可不开口）的那一刻，其中一项必为原文。
2. **笑声看得见**：界面只留一个与故事同源的量——“满座笑声”；众人笑时满屏“哈”字、人物前仰后合，结局清点这一日的“账”。
3. **地点即人物**：潇湘馆的竹与书、秋爽斋的大案与《烟雨图》、蘅芜苑的雪洞素净，全按原文陈设绘制。
4. **原话优先**：对白尽量直录原文，仅作删节与衔接。
5. **短而完整**：六折、约 10–15 分钟，可从头玩到三种结局之一。

### 4. 不做什么
- **不做数值养成或物品系统**：原著此回没有与之对应的张力。
- **不做牙牌的真实规则玩法**：令的趣味在“说什么”，不在点数；且凤姐鸳鸯本就是“故意都令说错”。
- **不让玩家扮演贾母、凤姐或黛玉等**：视角一散，“被取笑者的自处”这一主题就淡了。
- **不展开“只听外面乱嚷”之后**：那是下回的事。
- **不配音频**：评测不考察。
- **蘅芜苑不做成可行走场景**：姥姥在其中无言无事，压缩为舟中过场。

### 5. 玩家会经历什么
1. **标题** →「入园」→ 三页引子（时间、身份、心事）。
2. **第一折 大观楼下**：同李纨说话 → 登梯上缀锦阁 → 贾母进园、凤姐插花 → **c1**。
3. **第二折 沁芳亭**：贾母问园子 → **c2**。
4. **第三折 潇湘馆**：竹径 **c3**（跌或不跌）→ 进屋看书架 → 软烟罗 **c4**。
5. **第四折 秋爽斋**：（插叙：凤姐鸳鸯定计）→ 鸳鸯嘱咐 **c5** → 入座、早宴 → 鸽子蛋 **c6** → 饭后赔不是 **c7** → 探春房板儿 **c8**。
6. **第五折 舟中**（过场）：凤姐撑船、残荷、蘅芜苑。
7. **第六折 缀锦阁下**：入席 → 逃席与否 **c9**（若此前婉拒或着恼，追加 **c9x**）→ 牙牌令四句 **c10–c13**。
8. **结局**：
   - **结局一「老风流」（原著走向）**：四句里至少三句说本色话 → 众人大笑，“只听外面乱嚷”。
   - **结局二「斯文的客」**：行了令，但多数说体面话或认罚 → 体面保全，满座无趣。
   - **结局三「我家去了」**：c5 婉拒或 c7 着恼之后，在 c9 逃席、c9x 执意不入席 → 贾母发话不强，姥姥退席早归。
   - 每个结局右侧列出“这一日·姥姥的账”（花、画、跌跤、软烟罗、板儿、笑声次数），随选择而变；可回标题或重开。

## 五、运行说明

### 启动
纯静态网页，无依赖、无构建。
- **直接打开**：在 Chrome 中打开项目目录下的 `index.html`（双击或拖入浏览器即可，`file://` 可用）。
- **或用一条命令**（在项目目录内）：`python3 -m http.server 8000`，然后访问 `http://localhost:8000/`。

画布固定 1280×720，按窗口等比缩放。字体使用系统自带中文字体（macOS：宋体-简 / 楷体-简；其他系统回退 Noto CJK）。

### 操作
| 操作 | 键盘 | 鼠标 |
|---|---|---|
| 行走 | ← → 或 A D | 点击地面走到该处 |
| 交谈 / 查看 / 前往 | 靠近后按 E、空格或回车 | 点击人物或标记 |
| 推进对话 | 空格 / 回车 / E | 点击画面 |
| 选择 | 数字键 1 2 3（或 ↑↓ 后回车） | 点击选项 |
| 标题、结局按钮 | 空格 / 回车 | 点击按钮 |

界面左上为当前折名与目标；右上为六折进度与“满座笑声”；金色菱形标出当前目标，目标在屏幕外时有方向提示。

### 评测跳转点
进入方法：在网址后加 `#jump=<编号>`，例如 `index.html#jump=c5`（已打开页面时改后缀也会即时跳转）。跳转后直接处于该状态并立即可操作；游戏无随机玩法，装饰性随机均用固定种子。跳转点默认带入“原著路线”的前序选择（另有说明者除外）。
